# Bitcoin Market Sentiment Analysis

## Objective

Analyze the relationship between Bitcoin market sentiment and trader performance using Hyperliquid historical trading data and the Fear & Greed Index.

## Dataset

- Historical Trader Data
- Bitcoin Fear & Greed Index

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- SciPy

## Analysis Performed

- Data Cleaning
- Exploratory Data Analysis
- Merge datasets
- Profitability Analysis
- Win Rate Analysis
- Trade Volume Analysis
- Coin Performance
- Statistical Testing
- Correlation Analysis

## Key Insights

- Profitability across market sentiments
- Win rate under Fear vs Greed
- Trading behavior during different market conditions
- Coin-wise performance comparison
